🧠 AI Coding Mentor
______________________________________________________________________________________________________
An AI-powered Chrome extension that helps you when you're stuck while solving coding problems on platforms like LeetCode.
Instead of directly giving you the solution, it acts like a mentor and gives you hints, explains mistakes, and helps you figure out the approach yourself.
_______________________________________________________________________________________________________
Features
💡 Progressive hints instead of directly giving the solution
🔍 Analyze and explain mistakes in your code
🧠 Get help with algorithms and approaches
💬 Ask questions and interact with the AI mentor
⚡ Designed to work alongside LeetCode
_______________________________________________________________________________________________________
Tech Stack :
▫️HTML
▫️CSS
▫️JavaScript
▫️Chrome Extension (Manifest V3)
▫️Gemini API
_________________________________________________________________________________________________________
Goal
The idea is simple: help me solve the problem instead of solving it for me.
